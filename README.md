# The Core plugin marketplace

This repository is the plugin marketplace for **The Core**, which gives you and your agents shared memory and work context through The Core's hosted MCP connector.

The plugin itself is in [`the-core/`](the-core/README.md). See that README for what it does, requirements and install steps for Claude Code, claude.ai (chat and Cowork), Codex CLI and the ChatGPT desktop app.

Quick install:

- Claude Code: `claude plugin marketplace add Mattslayga/the-core-plugin`, then `claude plugin install the-core@the-core`
- Codex: `codex plugin marketplace add Mattslayga/the-core-plugin`, then install **The Core** from `/plugins`

You need an admitted The Core alpha account; installing the plugin does not create one. The plugin contains no keys or tokens.

This repository is published from the private Core Edge source (`plugins/`). Do not open pull requests here; report problems through The Core.
